# 今日晚餐 🍚

> AI 帮你搞定每天晚饭吃什么，荤素搭配，时令食材，几个人吃就出几道菜。

---

## ✨ 功能特色

- **每次都不一样** — 随机菜系（川、粤、湘、东北、江浙…）+ 随机肉类，换一批还会主动避开上次的食材
- **时令感知** — 自动识别春夏秋冬，每次指定一种时令食材，其他菜用普通家常食材
- **按人数出菜** — 几个人吃就出几道菜，5人以上自动加菜；食材用量随人数实时换算
- **荤素搭配** — 每套菜谱保证至少 1 荤 1 素 1 汤
- **生成分享图** — 截图生成高清菜谱图片，长按保存发给好友
- **手机优化** — 底部悬浮按钮、安全区适配、大点击区域，完全适配微信 H5

## 🚀 快速开始

### 直接打开使用

用浏览器打开 `今日晚餐_mobile.html` 即可，无需安装任何依赖。

### 部署到公网（推荐）

**Vercel 一键部署（免费）：**

1. 将 `今日晚餐_mobile.html` 重命名为 `index.html`
2. 注册 [vercel.com](https://vercel.com)，新建项目，上传文件
3. 自动获得 HTTPS 域名，如 `jrwc.vercel.app`
4. 把链接发到微信，好友直接打开使用

---

## 💬 微信 H5 使用说明

部署到 Vercel 后直接将链接发到微信即可，无需任何额外配置。

微信内打开后的分享方式：

1. 生成菜谱后点击 **「📤 生成分享图」**
2. 弹出高清菜谱图片预览
3. **长按图片 → 保存到相册**
4. 在微信聊天界面发送给好友

如需自定义分享卡片（标题、描述、封面图），修改 HTML 头部的 og 标签：

```html
<meta property="og:title" content="今日晚餐 🍚 每天不重样">
<meta property="og:description" content="AI 帮你搞定每天晚饭吃什么">
<meta property="og:image" content="你的封面图地址">
```

## 📋 菜谱逻辑说明

```
人数 → 菜数规则
  1-4 人  →  人数 = 菜数（2人吃2道，4人吃4道）
  5人以上  →  人数 + 1 道（5人吃6道）
  上限 8 道，下限 2 道

每套菜谱结构
  必选：1 道荤菜 + 1 道素菜 + 1 道汤
  可选：半荤半素炒菜 / 凉菜 / 豆腐（根据人数补足）

随机维度（每次生成都不同）
  菜系：家常 / 川 / 粤 / 湘 / 东北 / 江浙 / 鲁 / 闽（8种）
  肉类：猪 / 鸡 / 牛 / 鱼 / 虾 / 羊 / 鸭 / 蟹（8种，换一批排除上次）
  时令：当季食材中随机抽 1 种指定使用
```
